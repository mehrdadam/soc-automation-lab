# SOC Automation Lab

A collection of practical projects focused on SOC automation, Splunk SOAR, AI-assisted security workflows, and detection engineering.

## Projects

### 1. SOAR IOC Pipeline

An AI-assisted pipeline that monitors The DFIR Report RSS feed, generates candidate Splunk detection queries using an AI model, and stores the results in Splunk SOAR for analyst review.

**Technologies:** Splunk SOAR, Python, REST API, AI models, Splunk SPL.

[View Project](./soar-ioc-pipeline/README.md)

## Security Notice

Projects in this repository are intended for educational and defensive security purposes. AI-generated detection content should be reviewed and validated before operational use.
